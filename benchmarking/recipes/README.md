# Recipes

How-tos for concrete benchmark setups. They are examples, not part of the harness: each
one uses your own `config/models.local.yaml` (see
[Your own models and runners](../README.md#5-your-own-models-and-runners)).

| Recipe | For |
|---|---|
| [ollama.md](ollama.md) | a local open-weight model, no API key |
| [claude-code.md](claude-code.md) | Claude models with a Claude subscription instead of an API key |

Add a recipe when you benchmark with a setup others could reuse.
